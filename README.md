## 🛠️ Technology Stack
- **HTML5 & Semantic Markup**: Fast, accessible, and structured for optimal SEO.
- **Vanilla CSS (Design System)**: Responsive grids, glassmorphism, earthy palette (`#17241C`, `#D4AF37`, `#F7F4EC`), and modern typography (*Playfair Display* & *Plus Jakarta Sans*).
- **ES6 JavaScript (`app.js`)**: Real-time shopping cart with `localStorage` persistence, promo code engine, interactive 30s simulator, and checkout modal.
- **Zero External Dependencies**: Instant loading without build tools or vendor lock-in.

## 🚀 How to Run Locally

You can run the site using any local web server:

### Option 1: Python
```bash
python -m http.server 8080
```
Then open: [http://localhost:8080](http://localhost:8080)

### Option 2: Node.js (npx)
```bash
npx serve -l 8080
```

### Option 3: Direct Browser Launch
Simply double-click `index.html` to open it in any web browser!
